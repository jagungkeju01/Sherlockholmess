PENTING: versi ini menyesuaikan website dengan kondisi ketika semua gambar diunggah satu per satu ke ROOT repository GitHub (sejajar dengan index.html), bukan ke folder assets.

Cara upload:
1. Buka repository Sherlockholmess di GitHub.
2. Upload dan replace 12 file kode dari ZIP ini di root repository.
3. Jangan menghapus atau memindahkan file gambar yang sudah ada. Biarkan gambar sejajar dengan index.html.
4. Commit changes, lalu tunggu GitHub Pages selesai deploy.
5. Buka website dan lakukan refresh penuh / hapus cache jika gambar lama masih tersimpan.

Jika gambar ternyata berada di folder assets, bukan di root, jangan gunakan paket ini sebelum memindahkan gambar atau menyesuaikan path.
